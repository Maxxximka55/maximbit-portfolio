MAXIMBIT PORTFOLIO PRO — ИНСТРУКЦИЯ

10 HTML-файлов (8 кейсов + терминал-демо + главная), собранных по стандартам из html-skills-claudeai.zip:
- Ни одного innerHTML (безопасный DOM через createElement / textContent)
- Типографика Google Fonts с нативной кириллицей (Unbounded + Golos Text + JetBrains Mono)
- Inline SVG-диаграммы и графики, print-стили (@media print), мобильный адаптив и WCAG AA контраст
- Переключатель языка RU | EN с плавным эффектом печати во всех файлах (синхронизируется через ?lang=en)
- Без внешних контактов в теле страниц

СОСТАВ АРХИВА:
1. index.html                      — Главная витрина портфолио + живой калькулятор с копируемым брифом
2. tg-miniapp-store-prototype.html — CASE 01: Интерактивный Telegram Mini App магазин + live-тюнер тем и анимаций
3. python-bugfix-code-review.html  — CASE 02: Разбор ремонта сломанного бота после ИИ (Before/After Diff + Risk Map)
4. bot-architecture-topology.html  — CASE 03: Интерактивная SVG-топология продакшн-бота на Ubuntu VPS
5. bot-analytics-explorer.html     — CASE 04: Веб-админка заказов/логов (фильтры, SVG-график, CSV/JSON экспорт)
6. p2p-terminal-live-demo.html     — CASE 05: P2P-терминал в рамке телефона (работает через terminal-demo.html)
7. terminal-demo.html              — демо-копия терминала с подставным мостом, тестовые данные, БЕЗ доступа к рынку
8. p2p-bot-schema-erd.html         — CASE 06: Кликабельная ER-диаграмма схемы БД бота

9. payments-comparison-matrix.html — CASE 07: Матрица выбора оплаты (Stars / ЮKassa / CryptoBot), актуально на 20.11.2026
10. project-roadmap-timeline.html  — CASE 08: Дорожная карта проекта (Gantt с зависимостями)

ВАЖНО: p2p-terminal-live-demo.html и terminal-demo.html должны лежать в одной папке.
Не выкладывай боевой terminal.html в публичный репозиторий: в портфолио только демо-копия.

КАК ЗАДЕПЛОИТЬ НА БЕСПЛАТНЫЙ GITHUB PAGES ЗА 3 МИНУТЫ (С ТЕЛЕФОНА ИЛИ ПК):
1. Создай публичный репозиторий на GitHub (например, maximbit-portfolio).
2. Залей все HTML-файлы в корень репозитория.
3. Settings -> Pages -> Source: Deploy from a branch -> main / root -> Save.
4. Через 1 минуту получишь живую ссылку вида https://<твой-логин>.github.io/maximbit-portfolio/
5. Сделай аккуратные скриншоты каждого из 8 кейсов и добавь их в раздел «Портфолио» на Kwork и в галереи объявлений на Playerok.
